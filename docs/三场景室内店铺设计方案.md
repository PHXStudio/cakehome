# 三场景室内店铺设计方案（Zone 1~3）

> 2026-09-13 · 目标：把 Zone1/2/3 从「庭院」改为**三个不同风格的室内店铺**，
> 每场景 **5 个可升级部件 × 4 档**，背景**朴素简洁**、部件**占比大且体现品质递进**。

---

## 一、实测技术约束（坐标设计的地基，全部从 prefab/scene 读出）

| 项 | 实测值 | 结论 |
|---|---|---|
| Canvas Scaler | `ScaleWithScreenSize`，参考 **1080×1920** | 设计参考分辨率 |
| `m_MatchWidthOrHeight` | **1（Match Height）** | 高度恒 1920；宽度随机型 886~1080 |
| `Zone Container` | anchor `(0,0)-(1,1)`、sizeDelta `0×0` | 参考空间 = **1080×1920，中心为原点** |
| 背景 rect（旧） | `1882 × 3345.8`，pos `(59, 0)` | 🔴 **可见区仅中央 57.4%**，四周被裁掉 |
| 背景原图 | `941 × 1672`，缩放系数正好 **2.0** | 印证上式 |
| B1/B3 `preserveAspect` | **0（stretch）** | 🔴 会把方图拉变形，必须改 1 |
| B2/B4/B5 `preserveAspect` | 1 | 保持 |
| `Zone 1/2/3.prefab` | 三者**共用同一批 `Scene/Zone1/z1_*` 图** | 改素材必须落到**各自独立目录** |
| `buildingId` | 三 Zone 均为 `building_1~5`，各 4 级升级 | 存档/成本不动，只换美术 |

### 两条硬性修正
1. **背景直出 1080×1920**，prefab `sizeDelta` 同步设 `1080×1920` → 1:1 铺满、零裁切。
2. **5 槽位统一 `preserveAspect = 1` + 方图配方框**，位置按本文档重排。

## 三、槽位与布局（三场景共用一套规则，坐标按 Zone 微调）

参考空间 1080×1920，`anchor = (0.5, 0.5)`，`pivot = (0.5, 0.5)`，UI 坐标 **y 向上**。

### 最终布局：后墙 3 件 + 前景 2 件

> 中途试过「4 件一排 + 1 件前景」，但每件只能宽到 ~250，物件太小。
> 改 3+2 后后墙排每件 352 宽，视觉占比显著提升。

| 分区 | buildingId | 框 (w×h) | 中心 x | 底边 y |
|---|---|---|---|---|
| 后墙中（主件） | `building_1` | 352×405 | 0 | 交界线 −18 |
| 后墙左 | `building_2` | 352×405 | −364 | 交界线 −18 |
| 后墙右 | `building_4` | 352×405 | +364 | 交界线 −18 |
| 前景左 | `building_3` | 460×520 | −250 | **−840** |
| 前景右 | `building_5` | 460×520 | +250 | **−840** |

### 墙地交界线（逐行亮度跳变实测）

| Zone | 交界线距顶 | **UI y** | 依据 |
|---|---|---|---|
| z1 | 62% | **−230** | 墙面 230 → 46% 起护墙板 170 → 62% 起地板 |
| z2 | 67% | **−326** | 墙面 220 → 46% 起鼠尾草绿墙裙 144 → 67% 起地板 |
| z3 | 62% | **−230** | 白砖墙 225 → 54% 拱窗框 → 62% 起暖石砖地板 |

（UI y = 960 − 百分比 × 1920）

### 三条硬约束（优先级从高到低）

1. **物件必须"站在地板上"**：底边落在交界线略下方（`−18px`）。
   浮空是最刺眼的破绽。
   ⚠ 符号坑：UI y 向上、屏幕 y 向下 → 「底边下移」= UI y **减**。写成加号会让物件浮空 15px。
2. **框的长宽比要贴近素材长宽比**。`preserveAspect` 按 `min(box_w/img_w, box_h/img_h)` 缩放：
   框比素材"更瘦高"会被宽度卡住、上下留空；反之被高度卡住。
   实测素材高宽比 0.9~1.2（柜/桌类），框取 1.15。
3. **5 件互不重叠**，且前景件底边 ≥ −840（底部导航栏高 120，占 UI y −960~−840）。

## 六、Prefab 改造要点（接 `apply_zone_rooms.py`）

1. **Background**：sprite → `z{N}shop_background`；`sizeDelta = 1080×1920`；`anchoredPosition = (0, 0)`
2. **5 个 Building**：sprite 序列 → `z{N}shop_building{M}_*_{tier}`（default = tier1，upgrades[0..2] = tier2/3/4）
3. **RectTransform**：按第三节坐标表写 `anchoredPosition` / `sizeDelta`
4. **Image**：`m_PreserveAspect` 全部置 `1`
5. **Zone2/3 独立**：不得再指向 `Scene/Zone1/*`，避免三场景互相污染
6. `Scene/Zone1/z1_*`（22 张）保持庭院原版不动
