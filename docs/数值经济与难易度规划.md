# CakeHome 数值经济与关卡难易度规划

> 版本：2026-09-01 · 状态：规划中 · 基于全量数值提取（200 关 + Merge 合成经济）

## 0. 背景

用户试玩反馈：**玩 1 小时就腻**。定位根因在数值经济与关卡难易度两大层面：
- 三消关卡**中后期无递增**（奖励固定、难度平坦、机制稀缺、无计时）
- 经济**金币过剩、能量错配、钻石封闭**

本文档为数值梳理 + 问题诊断 + 分阶段优化规划。

## 2. 经济循环分析

```
金币流：
  来源 ── 三消通关(20+表现) ── 局内消除(5/棋×连击) ── Merge订单(sell×2) ── 卖物(sell) ── 宝箱
  出口 ── 建筑升级(565→3955→9605) ── 道具(100/5个)
  ⚠️ 防过剩门存在 → 供应＞出口 → 金币后期贬值

能量流：
  来源 ── 2min/1（上限50）── 升级奖励(25/级) ── 能量棋(头奖100)
  出口 ── 三消门票10(赢返还=免费) ── Merge生成器(1/次=黑洞)
  ⚠️ 三消赢=免耗 → 玩法偏三消，门店生成器成纯消耗 → 门店被冷落

钻石流：
  来源 ── IAP（20钻=100能量）
  出口 ── 补能量/宝箱/礼包
  ⚠️ 免费玩家钻石无获取途径、出口单一
```

### 核心失衡（3 项）

| # | 失衡 | 证据 | 后果 |
|---|---|---|---|
| 1 | **金币过剩** | 防过剩门 2.5/2/1.5×min升级费触发 | 金币贬值，消费动力弱 |
| 2 | **能量错配** | 三消赢返还=免耗；Merge 生成器 1/次 | 玩法倾斜三消，门店冷落 |
| 3 | **钻石封闭** | 免费玩家无获取途径，出口仅 IAP 相关 | 免费玩家钻石无感 |

## 4. 优化规划

### 4.1 三消难易度重构（解决"腻"）

| 措施 | 方案 | 优先级 |
|---|---|---|
| **奖励递增** | `coinsReward = 20 + 关数×0.5`（封顶 120）；连击加成保留 | P0 |
| **引入计时** | 40 关起 20% 关限时（60-120s），100 关后 40% | P0 |
| **曲线单调化** | 前 50 关 tile 27→90 缓升，中后 90→180 缓升；类型随关递增 7→17 | P1 |
| **机制多样化** | 效应关占比提至 30%+：冰块→锁链→传送门渐进解锁 | P1 |
| **新手平滑** | 关 1-3 保持 5×5/27 棋，关 4+ 才加类型 | P0 |

### 4.2 经济再平衡

| 失衡 | 方案 | 优先级 |
|---|---|---|
| **金币过剩** | 增加出口：道具限时折扣、蛋糕皮肤（金币买）、Merge 订单可刷稀有组件 | P1 |
| **能量错配** | 三消"赢返还"改"赢返 5、输扣 5"；或 Merge 生成器 g5+ 每 3 次省 1 能量 | P1 |
| **钻石封闭** | 三消全关/高分/Merge 满级给钻石；每日首胜送 1 钻 | P2 |

### 4.3 玩法深度（长期粘性）

| 方向 | 方案 | 优先级 |
|---|---|---|
| **订单目标** | Merge 订单显示目标链/进度，完成整套给里程碑奖励 | P1 |
| **合成图鉴** | 13 条链可视化进度，收集解锁称号/装饰 | P2 |
| **每日挑战** | 每日指定关卡（限时/限制道具）+ 首通双倍 | P2 |
| **成就** | 最高连击/单关全清/首个 g12/首栋满级建筑 | P2 |
